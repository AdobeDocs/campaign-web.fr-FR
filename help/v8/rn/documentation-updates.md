# Mises à jour de la documentation {#latest-updates}

Cette page répertorie toutes les mises à jour de la documentation d’Adobe Campaign Web.

## Juin 2026 {#june-2026}

* Ajout d’une note sur les exigences en matière d’encodage pour les diffusions courrier ciblant les langues CJC (japonais, coréen, chinois simplifié, chinois traditionnel). Le codage Latin-1 (1252) par défaut ne peut pas représenter les caractères CJC, ce qui entraîne un prévisualisation de fichier vide. Les utilisateurs et utilisatrices doivent sélectionner UTF-8 (65001) dans les paramètres de format d’extraction. [En savoir plus](../direct-mail/content-direct-mail.md)
* Ajout d’une page sur les directives de la CNIL pour les pixels de suivi d’e-mails et les fonctionnalités Adobe Campaign Standard associées. [En savoir plus](https://experienceleague.adobe.com/fr/docs/campaign/campaign-v8/new/cnil-pixel-tracking){target="_blank"}

## Décembre 2025 {#december-2025}

**Date : 1er décembre 2025**

* Réorganisation du guide de documentation de la génération de contenu avec des pages consolidées pour la [génération de contenu complet](../content/generative-full-content.md), la [génération de texte](../content/generative-text.md) et la [génération d’images](../content/generative-image.md).
* Ajout du [guide des bonnes pratiques en matière de prompts de génération de contenu](../content/ai-assistant-prompting-guide.md) pour aider les utilisateurs et utilisatrices à créer des prompts efficaces.
